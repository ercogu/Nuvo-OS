# Roadmap (путь проекта)

Это карта пути проекта, разделённая на этапы. Эта дорога будет заполняться постепенно новыми задачами.

# Этапы

|№|Этап|Статус|
|---|---|---|
|000|[Настройка окружения](000_Настройка_окружения.md)|Выполнен|

# Что должно быть в этапах?
1. Описание этапа и его смысл;
2. Цель этапа;
3. Теория к этапу;
4. План выполнения этапа;
5. Отчёт о выполненном этапе.

# Что не приветствуется в этапах:
1. Лирические отступления и вода в тексте;
2. Орфографические ошибки;
3. Отсутствие описания, цели или теории;
4. Отклонение от заданного плана;
5. Неполностью оформленный отчёт.

# Как правильно оформлять этап?
Этапы оформляются в этой папке, в файлах с расширением `.md`. Другие форматы не приветствуются.

Имя файла: `NNN_Название_этапа.md`, где `NNN` - номер этапа из трёх цифр.

Скриншоты к отчёту хранятся в `docs/resources/roadmap/stageNNN/` и подключаются относительным путём `../../resources/roadmap/stageNNN/<имя>.png`. У каждого скриншота есть подпись с описанием.

Пример:
```markdown
# Этап NNN. <Название этапа>
Цель: <...>

# 1. Описание этапа
<Описание этапа строго по правилам, без воды и лирики>

# 2. Теоретическая часть
<Теория, необходимая для выполнения этапа>

# 3. План
<План, необходимый для выполнения этапа>

# 4. Отчёт
<Скриншоты выполненной работы с описанием>
```
